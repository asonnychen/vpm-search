# 只做一套明亮"测速终端"主题

界面同时承载表格与日志两个主角，主题切换会带来两套间距与对比度校验，而这是自用工具，唯一需要优化的是长时间盯屏时的可读性。因此只提供一套主题：中性石墨底、深墨文字，深钴蓝作为唯一的强调色，表格行与日志行共用一套排版节奏。

最初按深色终端设计，实际使用后改为明亮；强调色先试过绿、洋蓝，最终定为深钴 `#1e40af`——绿色与语义色冲突，洋蓝饱和度过高，钴蓝在白底上够沉（白字 8.6:1），又能把"成功/超时/失败"留给语义色。

中性面不带色相，蓝色只出现在主按钮、选中行、复选框和焦点环。全站一套字体（Inter 打包进应用，最小字号 12px），数字只做 tabular 对齐、不换等宽字体。
