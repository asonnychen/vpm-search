# 日志按类型分表，各自配置保留期并可手动清理

日志不是一条流水，而是三种生命周期不同的东西：界面操作流水（人读，随会话滚动）、应用文件日志（排障用，JSON Lines，含 traceId 与入参出参）、探测日志（每次探测尝试一行原文，量最大）。混在一张表里，清理与保留策略只能取最保守的一个值。

因此界面把三类日志分成独立表格，每张表上方各有一行工具条：级别过滤、保留天数输入（默认 30 天）、清理按钮。清理按钮同时清空该表的界面内容与对应磁盘文件，并写一条"已清理"记录到应用日志里，避免"日志突然没了"变成新的排障谜题。

保留期到期的清理在启动时与每天零点各跑一次，按文件修改时间删除，删除动作本身也记入应用日志。默认 30 天是有意的：足够覆盖一次运营商换段周期，又不至于让磁盘无限增长。
